# 实验班成效的量化测评方案（专升本 2 年制）

> 对象：2026 级人工智能专升本 128 人，经专升本考试统一录取，全部入学。
> 其中按入学选拔考成绩**严格按分数线**取前 53 人进院长实验班，其余 75 人进普通班。
> 目标：两年后能回答一个问题——**实验班的教学方式本身有没有效**，
> 而不是"实验班本来就招了更强的学生"。

---

## 〇、这份方案要挡住的那个反驳

任何教改成效汇报都会遇到同一句质疑：

> "你们班成绩好，是因为你们挑走了好学生。"

这句话在方法论上是对的，叫**选择偏倚（selection bias）**。绝大多数国内教改论文
挡不住它，因为它们只有"实验班期末成绩 vs 普通班期末成绩"这一个对比。

我们这次的设置刚好能挡住它，而且是免费挡住的——因为三个条件同时成立：

| 条件 | 我们的情况 |
|---|---|
| 全部人选都已录取入学，只是分班不同 | ✅ 128 人全部在校，无人流失到校外 |
| 分班依据是**单一连续分数**，不是面谈或推荐 | ✅ 入学选拔考总分 |
| 切分点是**硬阈值**，不做调剂 | ✅ 严格取前 53 |

这三条凑齐，就构成一个**断点回归设计（Regression Discontinuity Design, RDD）**：
卡在分数线上下一两分的学生，能力上几乎不可区分，唯一的差别是一个进了实验班、
一个没进。比较这两拨人，就把"挑走了好学生"这个解释排除掉了。

**这是本方案里唯一一个能发高水平论文的东西。** 其余的前后测、问卷、访谈，
国内每年有几百篇，不稀奇。

## 一、测量时间线

专升本是 2 年制（大三、大四），时间窗比四年制短一半，所以测点必须密。

| 编号 | 时点 | 做什么 | 用途 |
|---|---|---|---|
| **T0** | 入学第 1 周（本次考试） | 选拔考 = 分班依据 + 基线 | RDD 的 running variable；ANCOVA 的协变量 |
| **T1** | 第 1 学期期中（约 8 周） | 概念锚题平行卷 A′ | 早期预警，看干预有没有反效果 |
| **T2** | 第 1 学期末 | 概念锚题 A″ + 首次迁移任务 | 第一个正式效应估计 |
| **T3** | 第 2 学期末（第 1 学年末） | 概念锚题 + 迁移任务 + 项目产出评分 | 中期主结果 |
| **T4** | 第 3 学期末 | 同上 + **延迟后测**（考 T2 教过、之后没再教的内容） | 保持性，本方案的主指标之一 |
| **T5** | 毕业前（第 4 学期末） | 综合迁移任务 + 毕业设计盲评 + 去向 | 终点结果 |

> 期间每周由系统自动采集主动使用率、连续天数、复检完成率——这部分不需要组织考试，
> 是事件流的副产品（`packages/engagement`、`packages/state/verification`）。

## 二、测什么：四类合法指标

CLAUDE.md 铁律 5 已经把合法的优化目标限定为四个。测评方案必须与它一致，
**否则会出现"系统优化 A、论文报告 B"的割裂**。

| 指标 | 怎么测 | 为什么是它 |
|---|---|---|
| **① 延迟后测表现** | T4 考 T2 学过、之后未复习的内容 | 当堂做对不算学会。这一条挡住"考前突击"型的虚假成效 |
| **② 迁移任务表现** | 给一个没见过的新场景，用学过的方法解决 | 挡住"只会做同类题"。迁移是理解的硬标准 |
| **③ 项目产出质量** | 双盲评分，量规见 §五 | 实验班是项目驱动的，产出是最终交付物 |
| **④ 主动使用率** | 非强制时段的系统使用行为 | Khanmigo 的教训：15% 的经常使用率，最大难题在行为不在算法 |

**明令不作为成效指标的**（与铁律 5 一致）：当堂正确率、做题数量、系统停留时长、
课程进度百分比。这些可以看，但不能写进论文的结果部分，也不能进任何激励。

## 三、核心工具：概念锚题清单（Concept Inventory）

### 3.1 为什么必须是"锚题"而不是"期末卷"

期末卷每年换、难度不可比，两年后拿 2026 的卷子和 2028 的卷子比分数是没有意义的。
纵向比较必须有**同一批题目**贯穿始终，这批题就叫锚题。

物理教育研究里的 FCI（力概念清单）是这个做法的原型：同一套题在课程前后各考一次，
用**归一化增益** Hake's *g* 衡量学习，使得不同起点的班级可以互相比较：

```
g = (后测% − 前测%) / (100 − 前测%)
```

*g* 的含义是"在你还不会的那部分里，你学会了多大比例"。
它天然消掉了前测起点的差异，这正是我们面对"专业差距很大"这批学生最需要的性质。

### 3.2 锚题的三条硬纪律

1. **考完不讲评、不返还、不公布答案。** 锚题一旦泄漏，两年后的重测就报废了。
   讲评只讲选拔专用题（见 §四的 B 部分）。
2. **每次重测用平行卷，不用原卷。** 平行卷通过**共同锚题等值**：
   每套卷保留 8–10 道完全相同的锚题用于分数等值，其余题目按同一命题规格替换。
3. **锚题库单独存放、单独权限。** 不进学生可见的题库，不进 `make practice` 的组卷池。

> 实现上：`question.origin='anchor'` 且 `retired=0`，组卷选题器默认排除该来源。

### 3.3 锚题覆盖的概念

对齐现有知识图谱的 `ML-01-*`（第 1 章 绪论与学习范式），这也是西瓜书第 1–2 章的内容：

| 概念 | 对应 KP | 常见错误认识（干扰项来源） |
|---|---|---|
| 模型/策略/算法三要素 | ML-01-01 | 把"最小二乘"当成算法而非策略 |
| 监督/无监督的判定依据 | ML-01-02 | 按标注数据占比判定，而非按训练是否用标注 |
| 分类/回归的判定依据 | ML-01-03 | 把"取整数值"当成类别 |
| 训练/验证/测试集的角色 | ML-01-04 | 用测试集反复调参 |
| 经验误差 vs 泛化误差 | ML-01-05 | 认为训练误差低即泛化好 |
| 过拟合/欠拟合的识别 | ML-01-06 | 见验证损失上升就加大模型容量 |
| 归纳偏好 / NFL 定理 | ML-01-08 | 认为存在普适最优算法 |
| 抽样偏差 | ML-03-01 | 把分布问题当拟合问题 |

## 四、T0 选拔考的双重身份（本次考试）

这是本方案里最需要小心的一处：**同一份卷子要同时干两件互相冲突的事**。

| | 选拔用途 | 基线用途 |
|---|---|---|
| 要什么 | 最大区分度，分数散得开 | 概念覆盖稳定、可重测 |
| 怕什么 | 大面积并列 → 无法切线 | 题目泄漏 → 两年后无法比较 |

解决办法是把卷子劈成两半：

- **A 部分 · 概念锚题（不讲评、进锚题库）**
  测的是西瓜书第 1–2 章的核心概念。这部分题两年内会反复重测。
- **B 部分 · 选拔专用题（考后可讲评）**
  测 1 周自学的吸收程度与编程实操，包括程序阅读与程序题。
  这部分一次性使用，考完可以公开讲评，不影响锚题。

**分数线切在 A+B 总分上。** 两部分都参与选拔，但只有 A 部分参与纵向比较。

### 4.1 RDD 对试卷的硬要求

断点回归成败取决于一件事：**分数线附近不能大面积并列**。
如果 128 人里有 20 个人卡在同一分，卡线两侧就分不开，RDD 直接报废。

由此推出三条命题约束：

1. **题量要大、分值要碎。** 50 题左右、总分 100 分、单题 1–5 分，
   使总分的可能取值足够密集。这也正是你要求"题量要大"的技术理由。
2. **避免大分值主观题占比过高。** 程序题总分控制在 10 分以内，
   否则一个题的判分波动就会把卡线附近的人洗牌。
3. **必须记录逐题作答，不只是总分。** 并列时用**项目反应模式**做二次排序
   （见 §4.2），并且事后要做题目分析（难度、区分度、点二列相关）。

### 4.2 并列处理规则（考前必须公布，考后不得更改）

严格按分数切会遇到第 53/54 名同分。事先定死规则，避免事后争议：

1. 总分高者优先；
2. 同分则 **A 部分（概念锚题）得分**高者优先——概念比操作更能预测长期发展；
3. 再同分则 **程序题得分**高者优先；
4. 仍同分则**交卷时间**早者优先（系统精确到秒记录）。

> 这套规则同时保证了 running variable 的严格单调，RDD 才是干净的。

## 五、项目产出质量的评分量规

两年里每人至少 3 次项目交付（T3、T4、T5 各一次）。双盲：评分者不知道学生属于哪个班。

| 维度 | 权重 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|---|
| 问题定义与需求拆解 | 15% | 照抄任务书 | 能拆成子任务 | 能指出任务书里的矛盾并给出取舍 |
| 方案选择的论证 | 20% | 只说用了什么 | 说明为什么用 | 有备选方案的对比与放弃理由 |
| 工程实现质量 | 20% | 能跑 | 有测试、可复现 | 有 CI、有回滚、有监控 |
| 结果的可信度 | 25% | 只报最好一次 | 有对照与重复 | 明确交代失败案例与边界 |
| 表达与答辩 | 20% | 念稿 | 讲清楚 | 能回答未预设的追问 |

第四维权重最高是刻意的：**能不能诚实交代自己方案的边界**，
是本项目全部设计哲学（不确定必须显式表达）在学生身上的投影。

## 六、统计分析方案

### 6.1 主分析：以 T0 为协变量的 ANCOVA / 差分中的差分

全样本 n=128（实验 53 / 对照 75）。

```
Y_it = β0 + β1·实验班_i + β2·T0分_i + β3·时点_t + β4·(实验班×时点) + ε
```

β4 是效应量。用 T0 作协变量吸收基线差异，这是"专业差距很大"这批学生的必要处理。

**功效估计**：n=128、前测与后测相关 r≈0.6、α=0.05、双侧，
可检出的效应量约 **Cohen's d ≈ 0.35–0.45**（中等偏小）。
这个量级对教育干预是现实的。

### 6.2 稳健性检验：断点回归

```
Y_i = α + τ·D_i + f(R_i − c) + ε ,  D_i = 1[R_i ≥ c]
```

R 是 T0 总分，c 是第 53 名的分数线，τ 是局部处理效应。用局部线性回归，
带宽按 IK/CCT 方法选。

**必须诚实交代的局限**：卡线附近的有效样本只有约 40–60 人，
RDD 在这个样本量下**功效不足**，只能检出较大的效应（d ≥ 0.7 左右）。
因此：

> **RDD 是用来排除选择偏倚这个替代解释的，不是主功效来源。**
> 论文里应当把 ANCOVA 作为主分析、RDD 作为识别策略的稳健性证据，
> 而不是反过来。把一个 n≈50 的 RDD 当主结果去投稿，会被审稿人打回来。

同时要做标准的 RDD 有效性检查：
- **操纵检验**（McCrary density test）——分数线附近的人数分布不应有跳跃。
  我们的分数由系统自动判分、学生无法预知分数线，这一条天然满足，但仍要报告。
- **协变量连续性**——性别、原专科专业、专升本考试成绩在断点处不应跳跃。

### 6.3 归一化增益

按 §3.1 计算每个学生的 *g*，报告班级均值 ⟨g⟩ 与分布。
这是与国际同类研究可比的指标，也是审稿人最认的一个。

## 七、效度威胁与对策

必须在论文的 Limitations 里写清楚，也必须在设计阶段就处理掉。

| 威胁 | 说明 | 对策 |
|---|---|---|
| **锚题泄漏** | 学生把题传给下一届或互相对答案 | 不讲评、不返还；平行卷；锚题单独权限 |
| **霍桑效应** | 实验班知道自己被观察，格外努力 | 无法消除，但要**测量**：两班用同一份学习投入问卷，把投入作为中介变量分析 |
| **教师混淆** | 实验班配了更好的老师 → 分不清是方法还是人 | **同一批教师同时教两个班**；若不可行，必须在论文里明确标注为局限 |
| **差异流失** | 实验班淘汰弱者，对照班保留 | 两年内**不得从实验班淘汰学生**，一旦淘汰整个设计失效；确有退出必须按 ITT 保留在原组分析 |
| **补偿性竞争** | 对照班学生知道落选后加倍努力 | 记录并在论文中讨论；这会**低估**实验效应，属保守偏倚，可接受 |
| **测试练习效应** | 反复考同一套锚题导致熟练 | 两组考同样次数，效应在组间抵消 |

**最需要盯住的是"差异流失"**。实验班中途淘汰学生在国内很常见，
但它会彻底摧毁这个设计——因为淘汰的必然是表现差的，剩下的自然"成效显著"。
这一条建议写进实验班管理办法：**两年内只进不出**。

## 八、预注册

在 T0 考试**之前**把以下内容登记存档（学院内部备案即可，或用 OSF 公开预注册）：

1. 主要结局指标（延迟后测、迁移任务、项目评分、主动使用率）
2. 分组规则（严格按 T0 总分取前 53，并列规则见 §4.2）
3. 主分析模型（ANCOVA with T0 covariate）与稳健性分析（RDD）
4. 样本量与功效估计
5. 不做的事：不中途调组、不剔除样本、不事后更换主指标

预注册是这套方案与"事后找显著结果"划清界限的唯一凭据。
Alpha School 被击穿正是因为拒绝独立验证——我们从第一天就按可被第三方核查设计
（CLAUDE.md 铁律：事件流只追加、状态可重算）。
