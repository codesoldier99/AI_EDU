# 选择题：干扰项从错误模式库里长出来

- **每个干扰项都要对应一种真实的想错方式**，例如"漏了链式法则的中间项"、
  "把归一化和标准化搞混"、"只看训练集分布"。随机编造的干扰项做不了诊断，
  学生排除掉它们不代表懂了。
- 题面只描述情境与问题，不带任何暗示正确答案的措辞（"显然"、"应该"、"最好"）。
- 四个选项长度接近，避免"最长的那个是对的"这种题面漏洞。
- 一道题只考一个知识点。要考两个，就出两道。
- 解析里写清楚**每个错误选项错在哪一步**，这段解析将来会被归入错误模式库。
