# 反例质疑：先把结论推到会塌的地方

- 不要问"你理解这个概念了吗"，问"什么情况下它不成立"。
- 给出的反例要**具体到能算**：一组具体的数、一个具体的输入规模、一个具体的极端参数。
- 学生答不上来时，把反例的条件再收紧一格（例如从"很大"改成"取 10^6"），
  让他先做出预测，再去验证；预测错了本身就是有用的信息。
- 禁止在这一步替他把边界条件说完整。他说出"我原以为……但这里不成立"，
  这一轮才算有产出。
- 收尾用一句话把边界写成可检查的形式：「当 ___ 时，结论 ___ 失效，因为 ___」。
