# 院长工作室实验班 · 培养方案要点（节选）

## 1. 定位

面向人工智能与智能交通产业需求，采用**项目驱动**的培养模式。
实验班规模约 60 人、导师 10 人，同期运行 5–10 个真实产业项目。

## 2. 能力模块 M1–M8

| 代码 | 名称 | 内涵 |
|---|---|---|
| M1 | 数学与建模基础 | 用数学语言刻画问题并推导结论 |
| M2 | 编程与工程实现 | 把算法写成可运行、可维护的代码 |
| M3 | 算法设计与分析 | 选择、改造与分析算法 |
| M4 | 数据处理与特征工程 | 获取、清洗、构造特征并评估数据质量 |
| M5 | 模型训练与调优 | 训练、诊断与改进模型表现 |
| M6 | 系统集成与部署 | 把模型接入真实系统并稳定运行 |
| M7 | 工程质量与协作 | 测试、评审、版本与团队协作 |
| M8 | 技术表达与伦理素养 | 书面表达、答辩、数据安全与 AI 伦理判断 |

## 3. 两项制度性安排

- **免听不免考**：理论课可自学，但必须参加统一考试。
  过程完全个体化，出口有统一门槛。
- **30/70 考核**：专业课 30% 笔试 + 70% 实践。
  实践部分的评分依据由项目客观信号与代码审查支撑，不凭印象打分。

## 4. 项目学分认定原则

- 项目可折算课程学分，但须经学术指导委员会审核。
- 规则约束：单项目学分上限、必修环节不可被完全替代、
  知识点覆盖不足 25% 不予认定。
- 所有认定结论必须可追溯到具体知识点节点。

## 5. 学生分流与替补

依据能力画像（雷达图、成长曲线、项目贡献）做动态调整，
**不使用排名，不做全班排行榜**，只看个人成长轨迹与项目产出。
