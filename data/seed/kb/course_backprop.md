# 讲义：反向传播与链式法则

## 1. 从计算图说起

一个神经网络的前向计算可以画成有向无环图：每个节点是一次运算，边上流动的是张量。
设两层网络：z1 = W1·x + b1，a1 = σ(z1)，z2 = W2·a1 + b2，L = ℓ(z2, y)。
把它画成图之后，"求某个参数的梯度"这件事就变成了"沿边把导数乘回去"。

## 2. 链式法则是唯一的机器

∂L/∂W1 = ∂L/∂z2 · ∂z2/∂a1 · ∂a1/∂z1 · ∂z1/∂W1。

四个因子分别是：损失对输出的导数、上层权重、激活函数导数、本层输入。
学生在这里最常见的错误有三种：

1. **漏掉激活函数的导数**（把 ∂a1/∂z1 当成 1）。这是最典型的错，占比过半。
2. **矩阵维度对不上**却强行转置，实际上是没弄清 ∂z/∂W 的形状约定。
3. **把 ∂L/∂z2 与 ∂L/∂a2 混为一谈**，在 softmax + 交叉熵处尤其容易出错。

若一个学生反向传播反复出错，先不要重讲反向传播——**回去检查他的链式法则**。
经验上，八成的"反向传播不会"其实是"复合函数求导不熟"。

## 3. 为什么 softmax + 交叉熵可以合并

当损失是交叉熵、输出层是 softmax 时，∂L/∂z = ŷ − y，形式异常干净。
这不是巧合，而是指数族分布与对数似然配对的结果（见 ML-05-08）。
记住这个结论可以省掉一层求导，但**必须知道它成立的前提**，
否则换一个损失函数照抄公式就会错。

## 4. 梯度消失的机理

sigmoid 的导数最大值只有 0.25。十层网络意味着最多 0.25^10 ≈ 1e-6 的缩放。
这就是为什么深层网络在 ReLU 出现之前难以训练。
理解这一点，才能理解 He 初始化、批归一化、残差连接分别在补哪一环。
