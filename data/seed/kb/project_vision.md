# 项目技术文档：产线零件表面缺陷检测

## 1. 业务背景

合作企业产线日产 4 万件，人工质检 3 人三班倒。缺陷率约 0.6%，
其中划痕占 62%、凹坑 21%、异色 11%、其他 6%。
**企业最怕漏检**：一件漏检流到客户端的赔付成本约等于 3000 次误检的复检成本。

## 2. 由此决定的技术取向

- 主指标是**召回率**（漏检率 ≤ 0.5%），精确率作为约束（≥ 60% 即可接受）。
- 报告必须用 PR 曲线，不用准确率。
- 阈值在验证集上按代价函数选：cost = 3000 × 漏检数 + 1 × 误检数。

## 3. 数据情况

- 有标注样本 4200 张，其中缺陷样本仅 260 张（严重不平衡）。
- 同一零件在不同工位被拍摄多次 —— **必须按零件 ID 分组切分**，否则严重泄漏。
- 光照条件在早晚班之间有明显差异，采集需覆盖两班。

## 4. 已验证有效的做法

1. ImageNet 预训练权重微调，冻结前两个阶段，学习率 1e-4 起。
2. 针对划痕做旋转 + 轻微仿射增强；**不要做颜色抖动**（异色本身是缺陷类别）。
3. 类别权重按逆频率设置后，召回率提升约 9 个点。

## 5. 已验证无效或有害的做法

- 直接做全图随机切分：验证集指标虚高 15 个点。
- 用 SMOTE 合成图像特征：产生了现实中不存在的纹理，现场表现下降。
- 只看 mAP 不看逐类别召回：异色类召回长期低于 40% 却被总指标掩盖。

## 6. 交付物

设计文档、评测报告（含 PR 曲线与阈值论证）、误判样本归因表、部署手册、伦理与数据合规自查表。
