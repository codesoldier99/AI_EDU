# 项目技术文档：园区自主配送 AGV

## 1. 系统组成

- 感知：16 线激光雷达 + 前视相机 + 轮式里程计 + IMU
- 计算：车载边缘计算盒（8GB 内存，NPU 算力约 8 TOPS）
- 软件：感知节点 → 定位节点 → 规划节点 → 底盘控制，节点间用消息总线通信

## 2. 交付指标（与企业约定）

| 指标 | 要求 | 当前基线 |
|---|---|---|
| 任务跑通率 | ≥ 95% | 0.82 |
| 定位 RMSE | ≤ 0.15 m | 0.21 m |
| 障碍物漏检率 | ≤ 2% | 4.7% |
| 端到端时延 | ≤ 120 ms | 180 ms |

## 3. 历史踩坑记录（重要）

1. **训练服务偏斜**：训练时图像做了归一化，车载推理漏了这一步，
   线下 mAP 0.83、线上 0.41。教训：预处理必须与模型一起打包。
2. **时间戳未对齐**：雷达与相机时间戳差 40 ms，融合后定位漂移。
   教训：先做时间同步，再谈算法。
3. **在测试路段调阈值**：把验收路段当验证集用，交付时指标掉了 12 个点。
4. **未固定随机种子**：两次训练结果差 3 个点，无法判断改动是否有效。

## 4. 边缘部署要点

- 显存受限时优先做 INT8 量化，其次才是换小模型。
- 批处理在车载场景收益有限（请求是逐帧的），重点在算子融合与内存复用。
- 国产芯片适配需重新导出模型格式，注意算子支持列表。
